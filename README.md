## 🛠️ Applications & Tools Included

### 🐍 Python Applications
1. **Mofi**: Moment-curvature diagrams using the Fiber Method (cracking, yielding, and chord rotation).
2. **LiSa**: Influence lines for multi-ribbed open sections based on Engesser theory, with export functionality to Excel and AutoCAD.
3. **PaLib**: Calculation of embedment depth for free sheet pile walls with soil-water interaction.
4. **PaVin**: Restrained sheet pile wall design, embedment depth, and interaction diagrams.
5. **TeVi**: Modal analysis of two-storey Grinter frames (periods, mode shapes, participating masses).
6. **Barros**: Barros theory for embankments (earth pressure on walls and drainage flow rate).

### 📐 Matlab Applications
1. **Seismic Signal Analysis (Analisi Segnali Sismici)**: Data download from ITACA, calculation of PGA/PGV/PGD, Arias Intensity, and Husid Plot.
2. **Hazard Analysis (Analisi Pericolosità)**: Hazard curves and disaggregation for linear seismic sources using the Gutenberg-Richter law.
3. **Response Spectra (Spettri di Risposta)**: Response spectra and pseudo-spectra generation from accelerometric signals using the Newmark method.
4. **Joint & Stirrups Design (Verifica Nodi e Staffe)**: Shear-tension/compression verification in beam-column joints and stirrup design according to Eurocode 8 (EC8).
5. **Uniform Hazard Spectrum (Spettro Pericolosità Uniforme)**: UHS generation and disaggregation using 5 attenuation laws for customizable return periods.
