Structural Engineering Student

Graduated in Civil and Structural Engineering from the University "Federico II" of Naples. I developed several technical software tools during my university years, now available for professionals and students. In addition, my university notes covering the main subjects of the degree programme are available for free.

Below you will find the descriptions of my applications, developed in Python and Matlab, which can be downloaded from my GitHub profile.

Mofi

Python

Moment‑curvature diagrams using the Fiber Method. Cracking, yielding, and chord rotation.

LiSa

Python

Influence lines for multi‑ribbed open sections. Engesser theory, export to Excel/AutoCAD.

PaLib

Python

Embedment depth for free sheet pile walls with soil‑water interaction.

PaVin

Python

Restrained sheet pile wall: embedment depth and interaction diagrams.

TeVi

Python

Modal analysis of two‑storey Grinter frames: periods, mode shapes, participating masses.

Barros

Python

Barros theory for embankments: earth pressure on walls and drainage flow.

Seismic signal analysis

Matlab

Download from Itaca, PGA/PGV/PGD calculation, Arias Intensity, and Husid Plot.

Hazard analysis

Matlab

Hazard curves and disaggregation for a linear source. Gutenberg‑Richter law.

Response spectra

Matlab

Response and pseudo‑spectra from accelerometric signals. Newmark method.

Joint & stirrups design

Matlab

Shear‑tension/compression verification in joints, stirrup design according to EC8.

Uniform hazard spectrum

Matlab

UHS and disaggregation using 5 attenuation laws. Definable return period.

Installation notes

Python: Lightweight setup – no Python installation required.

Matlab: Available as Standalone (with Runtime) or Runtime‑included versions.

We recommend the Runtime‑included version for faster subsequent installations.
